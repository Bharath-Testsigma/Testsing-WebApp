# Testsing-WebApp

A simple 3-page shopping website demo built with plain HTML, CSS, and a little JavaScript — no frameworks, no build step.

## Pages
- **`index.html`** — Home (hero, featured products, newsletter)
- **`products.html`** — Shop (product grid with category filters)
- **`cart.html`** — Cart & order summary

## Run it
Just open `index.html` in any browser:

```bash
open index.html
```

## What works
About 60% of the buttons are functional:

**Functional** — nav links, add-to-cart (persists via `localStorage`), cart badge, category filters, quantity +/−, remove item, live subtotal/tax/total.

**Decorative (demo only)** — search, account/login, wishlist, sort, newsletter, social icons, promo code, checkout/payment. These show a "just for show" toast.
